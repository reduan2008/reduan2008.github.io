Configuración de Ollama

Para que la IA funcione desde tu ordenador, sigue estos pasos:

  1. Instala Ollama desde ollama.com.
  2. Ejecuta este comando en tu terminal: 
    ollama run nutboy02/Qwen3.6-35B-A3B-Claude-4.7-Opus-abliterated-uncenfull
  3. Inicia Ollama con CORS habilitado: 
    OLLAMA_ORIGINS="*" ollama serve
  4. En Windows PowerShell: 
    $env:OLLAMA_ORIGINS="*" ; ollama serve
