Configuración local de Ollama

  1. Instala Ollama desde ollama.com.
  2. Ejecuta en tu terminal: 
    ollama run nutboy02/Qwen3.6-35B-A3B-Claude-4.7-Opus-abliterated-uncenfull
  3. Inicia el servidor con CORS habilitado: 
    OLLAMA_ORIGINS="*" ollama serve
  4. Si estás en Windows PowerShell: 
    $env:OLLAMA_ORIGINS="*" ; ollama serve
  5. Luego abre esta página y escribe tu prompt.
